## 1. 项目概述

### 1.1 项目背景

智慧社区综合管理平台是一个面向现代社区的数字化管理解决方案，通过整合社区各类资源和服务，实现社区管理的智能化、信息化和便捷化。

### 1.2 开发范围

| 端 | 应用 | 技术栈 |
|---|------|--------|
| **后端** | SpringBoot微服务 | Java 17 + SpringBoot 3.2 + MyBatis-Plus |
| **前端** | Web管理后台 | Vue 3 + TypeScript + Element Plus + Vite |

### 1.3 开发原则

- **敏捷迭代**：每个Phase独立可交付
- **测试驱动**：每阶段完成后进行E2E测试
- **文档优先**：每个功能点必须配套文档
- **代码规范**：遵循阿里巴巴Java/Vue规范
