# 智慧社区业主端

## 入口与身份

- 业主登录：`http://127.0.0.1:5174/community/login`
- 物业管理登录保留在 `/login`。普通业主从任一入口登录均进入 `/community/home`。
- 社区端只接受启用的 `userType=1` 普通业主，不允许管理员模拟业主身份。
- 本机已有账号 `owner001`，密码 `本机初始化时自行设置的密码`。正式部署前应修改演示密码。
- 两个登录入口均不预填管理账号或密码。

## 功能

社区首页、智能问答、邻里二手、社区广场、我的房屋、我的账单、我的车辆、在线报修及评价、投诉建议、公告阅读、活动浏览、便民电话、个人资料和修改密码。

报修和投诉通过居民专用接口创建，物业管理端可处理同一条业务记录；处理结果回到业主端展示。不另建重复业务表。

## 权限边界

- 后端通过已解析的控制器方法进行授权，不依赖前端菜单或地址前缀。
- 普通业主只能访问居民接口、本人资料/密码/头像以及退出接口。用户、角色、菜单、报表、AI配置、后端重启及旧管理接口均不允许访问。
- 每次请求重新检查账号启用状态与身份；JWT中不缓存管理员权限。
- 账号ID通过 `base_owner.user_id` 查找业主档案ID，二者不可混用。
- 房屋由 `base_owner_house` 的有效产权关系确定。账单、车辆、报修、投诉按当前业主档案过滤。未绑定档案时不能访问私人业务数据或提交工单。
- 提交工单不接受业主、处理人、状态等管理字段，房屋必须属于当前业主；评价仅允许本人已完成且未评价的报修。
- 公告只显示已发布、启用且发布时间已到的内容；活动不显示草稿。

## 本次范围

### 智能问答 `/community/qa`

复用系统已配置的兼容 OpenAI 模型，通过业主专用异步提问、结果轮询及本人历史记录接口调用。仅提供本人未缴清账单、本人报修及公开公告、活动、便民电话、空闲车位的受限快照。不使用管理端全局工具或共享向量检索，不允许修改业务数据。未绑定业主档案时不读取任何私人业务数据。问答记录按账号隔离；停用账号立即失去访问权限。

每位业主同时最多一个待处理问题，服务使用有界工作队列。运行中的问题保存在内存中，重启后可能失效；已完成并成功保存的问答历史仍在数据库中。模型未配置或上游失败时明确提示不可用，不泄露供应商原始错误或密钥。

### 邻里二手 `/community/marketplace`

支持分类、标题搜索、分页、图文发布、物品详情、卖家联系方式，以及本人发布的编辑、标记已售、下架和删除。公共列表只展示在售物品，不批量返回联系电话；联系方式在物品详情中展示。账号身份与初始状态由服务端设置，不能编辑他人物品或自行恢复已下架物品。当前采用联系卖家的交易模式，不提供在线支付、托管、订单或物流功能。

### 社区广场 `/community/posts`

支持公共帖子及我的帖子、分类搜索、图文发布、详情、编辑、删除、评论、回复和本人评论删除。公共页面仅展示可见帖子，隐藏或违规帖子不能通过业主编辑恢复公开，评论回复必须属于同一个帖子。普通账号不能设置置顶或管理状态。用户文本与AI回答以纯文本显示，不执行HTML。

帖子和二手图片每次限2MB，最多5张，支持JPG/PNG，边长不超过4096像素。未引用的已上传图片暂时保留，后续存储量增加时应配置定期清理。

当前项目是单社区数据模型，“公共帖子”是本平台业主共享广场，不代表多个独立小区系统之间的跨平台互联。

账单查询不模拟扣款；活动目前仅浏览，不接入报名；未接入家属/租户授权。

首页配图来自 Unsplash，保存在前端 `public/community-home.jpg`，是住宅示意图，并非本小区实拍：`https://images.unsplash.com/photo-1600585154340-be6161a56a0c`。

## 验证

- 后端：`mvn -f smart-community-parent/pom.xml test`
- 前端：`npm run build`
- 浏览器：`PLAYWRIGHT_CHANNEL=msedge PLAYWRIGHT_VIDEO=off npx playwright test tests/10-community.spec.ts --reporter=list`（PowerShell使用 `$env:` 设置变量）
- 真实接口及登录：同上命令指定 `tests/11-community-live.spec.ts`，只读验证既有演示账号，工单提交与防篡改由模拟接口测试和后端单元测试验证。
- 社区互动界面：`tests/12-community-interaction.spec.ts`；真实发布、跨业主评论及越权防护：`tests/13-community-social-live.spec.ts`，后者仅创建带有“自动验证临时记录”标记的记录并通过业主接口删除。
